# Variable-star data

Variable-star catalogues used by the AURORA workflow are kept in the repository-level `variable/` directory:

- Cepheids
- RR Lyrae
- ZZ Ceti
- Luminous blue variables
- Cataclysmic variables

They are intentionally not duplicated here. FITS data are source assets, while this `strona/variable/` folder reserves a clear location for future web-ready catalogue subsets or an interactive variable-star viewer.
