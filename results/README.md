# Web previews

This directory holds web-optimised derivatives of AURORA output files. The original 16K–32K maps and H.265 masters remain in the repository-level `results/` directory so the website stays practical to load.

Generated assets:

- `aurora-sky-preview.jpg` — 2.4K preview of the 16K Hammer all-sky map.
- `microlensing-poster.jpg` — video fallback / preview frame.
- `aurora-microlensing-preview.mp4` — H.264 browser preview of the AURORA microlensing animation.
